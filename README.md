# SIAK-ILMI

Sistem Informasi Administrasi dan Keuangan Darul Ilmi.

Aplikasi administrasi sekolah untuk membantu pengelolaan
data siswa, pencatatan pembayaran, dan rekapitulasi keuangan.

## Download

## Installation

1. Download APK.
2. Buka file APK.
3. Izinkan instalasi dari sumber tidak dikenal jika diperlukan.
4. Install aplikasi.
